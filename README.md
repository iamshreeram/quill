# Quill ✉️

A lightweight, system-wide clipboard text transformer powered by Claude. Copy text, hit a shortcut, and your clipboard is replaced with a polished version — ready to paste.

Quill learns your writing style over time and adapts its output to match.

**~624 KB binary. Zero GUI. Pure clipboard magic.**

## How It Works

```
1. Select text and copy    (Cmd+C / Ctrl+C)
2. Transform               (Cmd+Shift+C / Ctrl+Shift+C)
3. Paste the result        (Cmd+V / Ctrl+V)
```

Step 2 reads your clipboard, sends it to Claude with your configured instruction and writing context, and writes the transformed result back to your clipboard.

## Quick Start

```bash
# Build
cargo build --release

# Add to PATH
export PATH="$PWD/target/release:$PATH"   # bash/zsh
fish_add_path "$PWD/target/release"        # fish

# Initialize config + prompt profiles
quill init

# Set your API url, key, and user_name
$EDITOR ~/.config/quill/config.toml

# Install keyboard shortcut
quill setup
```

Then: select text → `Cmd+C` → `Cmd+Shift+C` → `Cmd+V`.

## Commands

| Command | Description |
|---|---|
| `quill init` | Create config, prompts dir, sample profiles |
| `quill setup` | Install keyboard shortcut |
| `quill --now` | Transform clipboard using default instruction |
| `quill --now -p formal` | Transform using a prompt profile |
| `quill learn` | Analyze history, update writing context |
| `quill` | Show usage + file paths |

## Configuration

All settings live in **external files** — no secrets, URLs, or API keys are stored in the source code.

A sample config is included in the repo as [`config.sample.toml`](config.sample.toml).

### Config File Location

| Platform | Path |
|---|---|
| **macOS** | `~/.config/quill/config.toml` |
| **Linux** | `~/.config/quill/config.toml` |
| **Windows** | `%USERPROFILE%\.config\quill\config.toml` |

### Directory Structure

```
~/.config/quill/
├── config.toml       # API connection, default instruction, shortcut
├── context.md        # Your writing style preferences (auto-updated by `quill learn`)
├── history.jsonl     # Before/after transformation pairs (consumed by `quill learn`)
├── hotkey.sh         # Auto-generated by `quill setup` (macOS)
└── prompts/          # Prompt profiles
    ├── formal.txt
    ├── casual.txt
    ├── grammar.txt
    └── summarize.txt
```

### Config Sections

#### `[api]` — Claude API connection

| Field | Description |
|---|---|
| `url` | API endpoint URL |
| `key` | Your API key |
| `model` | Claude model identifier |
| `anthropic_version` | API version header |
| `user_type` | Auth header (e.g. `USER`) |
| `user_name` | Your user ID |
| `accept_invalid_certs` | Accept self-signed certs |

#### `[transform]` — What Claude does with your text

| Field | Description |
|---|---|
| `instruction` | Default prompt sent alongside your text |
| `system_prompt` | Constrains Claude’s output format |
| `max_tokens` | Max response length |
| `prompt_override` | Name of a prompt profile to use instead of `instruction` |

#### `[shortcut]` — Keyboard shortcut binding

| Field | Description |
|---|---|
| `macos` | skhd syntax (e.g. `cmd + shift - c`) |
| `windows` | Native hotkey (e.g. `ctrl + shift + c`) |

## Prompt Profiles

Prompt profiles let you switch between different transformation styles without editing `config.toml`.

Profiles are plain text files in `~/.config/quill/prompts/`. Each file contains one instruction.

### Built-in Profiles

`quill init` creates these sample profiles:

| Profile | File | What it does |
|---|---|---|
| `formal` | `formal.txt` | Formal business English |
| `casual` | `casual.txt` | Friendly, conversational |
| `grammar` | `grammar.txt` | Fix grammar and spelling |
| `summarize` | `summarize.txt` | Condense to 1-2 sentences |

### Using Profiles

```bash
# CLI flag (highest priority)
quill --now -p formal
quill --now --prompt casual

# Environment variable
QUILL_PROMPT=formal quill --now

# Config default (lowest priority)
# In config.toml: prompt_override = "formal"
```

Priority: `--prompt` flag > `QUILL_PROMPT` env > `config.toml prompt_override` > default `instruction`.

### Creating Custom Profiles

```bash
echo "Translate to Spanish. Return ONLY the translation." > ~/.config/quill/prompts/spanish.txt
quill --now -p spanish
```

## Writing Context & Learning

Quill maintains a **writing style context** that gets injected into every transformation, so Claude matches your preferred tone, vocabulary, and style.

### How It Works

1. Every transformation records a before/after pair in `history.jsonl`
2. Run `quill learn` — Claude analyzes your history and extracts style preferences
3. The result is saved to `context.md`
4. Future transforms include `context.md` so Claude follows your style
5. History is cleared after learning (context is the distilled output)

### Example

After a few transforms, run:

```bash
quill learn
```

Quill produces something like:

```markdown
# Quill Writing Context

## Preferences

- Keep text concise and direct
- Use a professional but approachable tone
- Avoid corporate jargon like "circle back" and "synergy"
- Use contractions for natural flow
- Prefer short sentences over complex ones
```

You can also **manually edit** `context.md` anytime — it's just a markdown file.

## Platform Setup

### macOS

Requires [skhd](https://github.com/koekeishiya/skhd) for global hotkeys:

```bash
brew install koekeishiya/formulae/skhd
skhd --start-service
```

Grant Accessibility access:
**System Settings → Privacy & Security → Accessibility → add `/opt/homebrew/bin/skhd`**

```bash
quill init      # create config + prompts
quill setup     # install shortcut
```

Usage: `Cmd+C` → `Cmd+Shift+C` → `Cmd+V`

### Windows

No extra tools needed — hotkey registration is native.

```bash
quill init      # create config + prompts
quill           # starts background hotkey daemon
```

Usage: `Ctrl+C` → `Ctrl+Shift+C` → `Ctrl+V`

### Changing the Shortcut

Edit `[shortcut] macos` in config.toml, then re-run `quill setup`.

macOS shortcuts use [skhd syntax](https://github.com/koekeishiya/skhd):

```
cmd + shift - c          # Cmd+Shift+C (default)
ctrl + shift - space     # Ctrl+Shift+Space
cmd + alt - t            # Cmd+Option+T
```
