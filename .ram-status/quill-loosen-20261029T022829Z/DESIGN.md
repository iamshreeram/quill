Relaxed rule (D): token alphabetic lowercase, len 5..=6, levenshtein==1, suggestion len>=token len, same first letter, suggestion in top-5000 list, token itself NOT in the list. Also len 4 allowed ONLY for insertion of one letter where suggestion in top-1000 (wich->which). Existing (A) permutation, (B) apostrophe and (C) len>=7 rules unchanged. Goal: fix arive/wich/adress, pick appointment over anointment. Tech words sudo/nginx/docker/kubectl/thx/pls/tmrw must stay untouched (existing tests).
3 Small deterministic rule table (new fn custom_lints(chars, prot) -> Vec<Lint>, Lint kind Grammar, single-token ReplaceWith spans so existing guards apply): (a) non-word irregular past forms -> correct form (buyed, teached, runned, goed, breaked, growed, knowed, thinked, bringed, catched, falled, feeled, gived, taked, writed, eated, drinked, swimmed, speaked, sleeped, standed, understanded, builded, sended, spended, maked, comed): NEVER singed/leaved (real words). (b) participle after have/has/had/'ve/'d (adjacent): went->gone wrote->written ate->eaten drank->drunk took->taken saw->seen gave->given began->begun did->done; and pronoun + seen -> saw (I|he|she|we|they|you seen). (c) could/would/should/must/might + of -> have. (d) then->than after a comparative (word ending 'er' from a small list or 'more|less|better|worse|rather'). (e) its->it's before a|an|been|not|going|too|so|very|really|just; it's->its before own|tail|name|way|color|shape|head|owner; (f) 'your welcome' ->you're welcome only when followed by 'to' or sentence end; their->they're before going|gonna|always|not|never|really|ready; (g) 'the affect of' -> effect; (some|good|any|great|useful|free|bad|my|your) advise -> advice; 'too the' -> 'to the'; (over|in|out|up|down|from) their + [.!?,] -> there. Case: if the token is capitalised, capitalise the replacement's first letter. Custom lints flow through the SAME safety filters and overlap removal as Harper lints.

# REVISION 3 AMENDMENTS (supersede anything above that conflicts)
- RegularIrregulars is NOT added to ALLOWED_RULES (its suggestion order is nondeterministic: HashSet of past+participle).
- Custom irregular table is (nonword, past, participle). Choose participle when the previous word (case-insensitive, adjacent) is one of have|has|had|'ve|having|been|be|being|was|were|is|are|am, else past. Entries: buyed bought/bought, teached taught/taught, runned ran/run, goed went/gone, breaked broke/broken, growed grew/grown, knowed knew/known, thinked thought/thought, bringed brought/brought, catched caught/caught, falled fell/fallen, feeled felt/felt, gived gave/given, taked took/taken, writed wrote/written, eated ate/eaten, drinked drank/drunk, swimmed swam/swum, speaked spoke/spoken, sleeped slept/slept, standed stood/stood, understanded understood/understood, builded built/built, sended sent/sent, spended spent/spent, maked made/made, comed came/come. Never singed/leaved.
- Precedence: after collecting Harper lints and custom lints, any Harper lint whose span overlaps an accepted custom lint is discarded BEFORE remove_overlaps (custom wins). This also ensures a spelling suggestion (teached->teacher) can never beat the table.
- Change 3(b) advise->advice is DROPPED (counterexamples 'Some advise caution.' and 'May the good advise the king.').
- New must-pass tests (C1/C2): 'I eated lunch.'->'I ate lunch.'; 'I have eated lunch.'->'I have eaten lunch.'; 'She has teached us.'->'She has taught us.'; synthetic overlap test (custom lint survives over a Harper lint on the same span); must-not-change: 'Some advise caution.', 'May the good advise the king.'.
- Only a feature branch is ever pushed (never main); PR only, no merge.
- (Rev 4, C3) Participle contexts also include the unambiguous contracted have forms: i've|you've|we've|they've|who've|could've|would've|should've|might've|must've (case-insensitive; also with the typographic apostrophe U+2019). For previous words ending in 's or 'd (she's, he's, it's, I'd, ...) and any entry where past != participle, the replacement is SKIPPED (text left unchanged); never default to past. Entries where past == participle (bought, taught, thought, ...) are replaced regardless of context.
- (Rev 4) Tests added: "I've eated lunch." -> "I've eaten lunch."; "She's eated lunch." and "I'd eated lunch." must not become "She's ate lunch." / "I'd ate lunch." (unchanged is acceptable); "She's buyed a car." -> "She's bought a car." (past==participle).
